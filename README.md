# CV académico de Elizabeth Lam Esquenazi

Perfil académico bilingüe para GitHub Pages, con selector English/Español y menú interactivo Follow.

## Publicar en GitHub Pages

1. Crea un repositorio nuevo y sube el contenido de esta carpeta.
2. En el repositorio, abre **Settings** y después **Pages**.
3. En **Build and deployment**, selecciona **GitHub Actions**.
4. Envía los archivos a la rama `main`. El flujo incluido construirá y publicará el sitio.

## Desarrollo local

```bash
pnpm install
pnpm dev
```

La compilación de producción se genera en la carpeta `out` con `pnpm build`.
